# 🚀 Getting Started

Clone Repository

```bash
git clone https://github.com/MridulSingh3/Full-Stack_-Mini-Projects-.git
```

Move Into Project

```bash
cd Journel_App
```

Install Dependencies

```bash
npm install
```

Run Application

```bash
npm run dev
```
